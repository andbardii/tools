# MacBook Generics

Parte della raccolta [Tools](../README.md). Script personali Zsh per configurazione e manutenzione di macOS:

- `new.zsh`: configurazione iniziale dell’ambiente.
- `optimizer.zsh`: operazioni di pulizia e manutenzione.

Leggi lo script scelto e adatta i comandi al tuo computer prima di eseguirlo: possono installare software, cambiare impostazioni o eliminare file. Non vengono eseguiti automaticamente dalla raccolta.
